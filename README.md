# 🏨 Hotel Booking Website

A hotel booking website frontend built using **HTML and CSS**. This project provides a travel booking interface where users can explore stays, discover destinations, view hotel deals, and explore travel-related activities.

## 📌 Project Overview

This project is a frontend design inspired by hotel booking platforms. It focuses on creating an attractive and user-friendly interface for exploring hotels and travel destinations.

## ✨ Features

* 🏠 **Homepage** – Clean layout with a navigation bar and banner.
* 🔍 **Search Section** – Interface for entering destinations, dates, and travellers.
* 🛏️ **Stay Categories** – Explore apartments, resorts, spas, and family-friendly stays.
* 🏨 **Hotel Deals** – Display hotel cards, prices, and discounts.
* 🌍 **Travel Destinations** – Explore beautiful places, nature, culture, and activities.
* 📱 **App Promotion Section** – UI section for mobile app downloads.
* 🔗 **Navigation Links** – Links between different website pages.
* 🎨 **Custom Styling** – CSS styling, cards, images, buttons, and hover effects.

## 🛠️ Technologies Used

* HTML5
* CSS3
